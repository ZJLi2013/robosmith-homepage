Overview

Scalable manipulation data is a major bottleneck for embodied intelligence. RoboSmith treats static assets as only the first step: generated or imported objects must become interaction-ready through asset admission, task-scene resolution, learned grasp proposals, deterministic feasibility filtering, policy onboarding, metadata-guided rollout, and dataset/evaluation export.

From sim-ready to interaction-ready Assets carry scale, pose, mesh audit, and policy evidence before they are used for data generation.
Metadata-guided grasping Learned 6-DoF proposals are filtered by robot/table feasibility and selected through reusable pose-family evidence.
Rollout-to-data path Episodes record success, failure modes, videos, and metadata for training and evaluation workflows.

Pipeline

asset generation/import
  -> asset audit and metadata update
  -> scene/task resolution
  -> learned 6-DoF grasp proposals
  -> deterministic feasibility filtering
  -> policy bucket onboarding
  -> metadata-guided rollout
  -> episode videos, metadata, dataset/eval outputs
