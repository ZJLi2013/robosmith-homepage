Overview

Scalable manipulation data is a major bottleneck for embodied intelligence. RoboSmith treats static assets as only the first step: generated or imported objects — rigid and articulated — must become interaction-ready through asset admission, task-scene resolution, learned grasp proposals, deterministic feasibility filtering, policy onboarding, metadata-guided rollout, and dataset/evaluation export. A concise Code-as-Policy (CAP) declaration decouples task intent from execution, so a single ~15-line spec can drive long-horizon, multi-step interaction episodes.

From sim-ready to interaction-ready Assets carry scale, pose, mesh audit, and policy evidence before they are used for data generation.
Code-as-Policy (CAP) A ~15-line declarative spec states what to do; RoboSmith resolves grasping, motion, and articulation into the how.
Metadata-guided grasping Learned 6-DoF proposals are filtered by robot/table feasibility and selected through reusable pose-family evidence.
Long-horizon articulated tasks Stateful articulation (e.g. a drawer joint) is chained with grasp + motion into multi-step open→pick→place→close episodes.
Rollout-to-data path Episodes record success, failure modes, videos, and metadata for training and evaluation workflows.

Pipeline

Code-as-Policy (CAP) task spec   (~15 lines: what, not how)
asset generation/import
  -> asset audit and metadata update
  -> scene/task resolution
  -> learned 6-DoF grasp proposals
  -> deterministic feasibility filtering
  -> policy bucket onboarding
  -> metadata-guided rollout
  -> episode videos, metadata, dataset/eval outputs

Code & Dependencies

RoboSmith is built on a stack of open ROCm-first components. The core engine is open source; the learned grasp planner (GraspGen) is NVIDIA research/eval-licensed and fetched from upstream.

RoboSmith Core engine: asset admission, scene/task resolution, feasibility filtering, metadata-guided rollout and dataset/eval export.
rocRecon Asset reconstruction & audit — turning generated/imported meshes into sim-ready, metadata-carrying assets.
rocRobo Collision-free motion planning sidecar (JAX/pyroki on ROCm) used for the rollout motion path.
GraspGen Learned 6-DoF grasp proposals (NVIDIA research/eval license). Run on ROCm via the spconv_rocm PTV3 backbone.
Interaction-SDG Workshop Self-contained, reproducible workshop (notebook + images) for interaction-ready data generation on AMD MI300.
spconv_rocm ROCm port of sparse-convolution ops, enabling the GraspGen PTV3 backbone on AMD GPUs.
